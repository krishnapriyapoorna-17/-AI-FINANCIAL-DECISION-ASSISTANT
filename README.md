# AI Financial Decision Assistant

AI Financial Decision Assistant is a Python-based financial analytics application designed for small businesses and enterprises. It processes transaction data to evaluate financial health, run cash flow metrics, and deliver AI-powered recommendations.

## How to Run

1. Activate the virtual environment:
   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

2. Run the Streamlit application:
   ```bash
   streamlit run app.py
   ```
